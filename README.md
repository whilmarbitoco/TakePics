# TakePics

**TakePics** is an automated webcam photo capture tool that allows you to capture images. It can be used for various purposes like monitoring, or just capturing snapshots automatically without manual intervention.

## Features

- 📸 Automatically captures images from your webcam.
- 🔑 Secure and private—no external data sharing.

## Installation

### Prerequisites

- Python 3.x

### Steps

1. Clone the repository:

    ```bash
    git clone https://github.com/whilmarbitoco/TakePics.git
    ```

2. Navigate to the project directory:

    ```bash
    cd TakePics
    ```

3. Run the application:

    ```bash
    python server.py
    ```

## Usage

Once installed, simply run the script to start capturing images at regular intervals. You can customize the interval and output directory in the configuration section.
